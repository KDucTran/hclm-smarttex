## Data source and license

The HCLM-SmartTex respiratory evaluation uses eight recordings (`a01`–`a04`, `b01`, and `c01`–`c03`) from the [Apnea-ECG Database, version 1.0.0](https://doi.org/10.13026/C23W2R), released by George Moody and Roger Mark through PhysioNet.

The Apnea-ECG data are available under the [Open Data Commons Attribution License v1.0 (ODC-By 1.0)](https://opendatacommons.org/licenses/by/1-0/). On first use, the script downloads the required waveform, header, and annotation files and verifies their SHA-256 checksums.
